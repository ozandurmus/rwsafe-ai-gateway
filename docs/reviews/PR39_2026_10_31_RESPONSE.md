| D-01 (P2) | **Fixed.** Both UI handlers (`/assets/**` and `/**`) use `AdminUi.ConfinedResolver`: on top of `PathResourceResolver`'s lexical location check, a file is served only when its real path (every symbolic link resolved, `toRealPath`) is a regular file inside the UI directory's real path. A link that points out of the directory, as a file or as a directory on the way, is the JSON 404; a link whose target stays inside is an ordinary file. | D-02 (P2) | **Fixed.** `CookiePolicy.check` refuses a Secure session cookie whose name lacks the `__Host-` prefix (an unprefixed or a `__Secure-` name), so a Secure deployment always keeps the browser's origin and `Path=/` binding whatever `RWSAFE_SESSION_COOKIE` says. The constructor's fallback defaults now match `application.yaml` (`__Host-rwsafe-session`, Secure). Test: `CookiePolicyTest.aHalfAppliedSettingIsRefused`. |
| D-03 (P2) | **Fixed.** The `ui` stage joins the optional CA files with a newline after each (`for pem in /tmp/corp-ca/*.pem; do cat "${pem}"; echo; done`), so a file without a final newline cannot glue its END line to the next BEGIN line. A shell loop rather than `awk 1` keeps the step independent of the base image's tools. Test: `tools/pilot/test_render.py` `test_the_ui_stage_joins_ca_files_with_a_newline` runs the Containerfile's own join on two synthetic files, one without a final newline, and checks every BEGIN and END marker is on a line of its own. |
