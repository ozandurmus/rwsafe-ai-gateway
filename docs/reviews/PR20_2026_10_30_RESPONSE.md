| D-01 (P0) | **Fixed.** The per-value base64 heuristic is removed. ## For the control plane worker

The data plane now refuses a snapshot with any field outside the contract on the document or a platform row, a scoped
rule with an empty class map, and a group name with a comma or a control character. The compiler emits exactly those
fields today for format 1; format 2 must do the same.
