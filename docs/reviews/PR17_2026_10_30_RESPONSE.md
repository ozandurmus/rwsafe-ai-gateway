## Confirmation review

Review: `PR17_2026_10_30_ARGON_DATAPLANE_DECODING_RECHECK.md` (brief commit 2817988). D-01 and D-04 closed; D-02 and
D-03 stayed open as D-05 (P0), D-06 and D-07 (P1). The orchestrator replaced the case-by-case retries with four rules,
each linear and inside the per-field decode budget; `realign`, the prefix stripping, the `/` split and the UTF-16LE
heuristic are removed. The tests carry the reviewer's exact failing cases.

| Id | Answer |
|---|---|
| D-05 (P0) | **Fixed.** (1) Bytes that are not strict UTF-8 are scanned through every view, never one chosen by a heuristic: UTF-8 with NUL removed and invalid sequences replaced, UTF-16LE and UTF-16BE at both byte parities; per class the most findings any view gave are kept, so a value is never counted twice. (2) Any base64 run of 12 or more characters inside a second decoded layer is a third layer and `UNDECODABLE_BLOB`, whatever it decodes to; its views are still scanned so the event keeps the classes. Tests: `nulPaddedAndUtf16BeLayersAreFound` (30 and 7 NUL bytes before the secret, UTF-16BE, UTF-16LE after an odd byte), `aThirdLayerIsABlobWhateverItDecodesTo` (a control byte, an invalid byte before a base64 secret, random bytes). `DecodingEndToEndTest.base64CloudKeyIsBlocked` now expects a double-encoded key to block as `UNDECODABLE_BLOB` with the secret counted: the key is itself a run inside the second layer. |
| D-06 (P1) | **Fixed.** Reasons have a severity (`Base64Layers.worse`): a terminating reason (`UNDECODABLE_BLOB`, the limits) outranks `EMBEDDED_FILE`, in `Base64Layers.flag` within a field and in `BodyInspector.inspectJson` across fields. Tests: `aBlobOutranksAnEmbeddedFile` (one field and two fields, both orders, a PDF before a third layer), and a third case in `responseWithAFindingBesideAFileOrWithABlobIsTerminated` (a PDF before a blob in a response is terminated, not answered 204). |
| D-07 (P1) | **Fixed.** A run that is not whole quanta of clean text is decoded at all four alignments (start offsets 0 to 3, each trimmed at the end to a multiple of 4), and every alignment goes through every view of D-05; the untrimmed whole run is read too, so an unpadded last quantum is not lost. Every decode is charged to the per-field budget (at most five per run character); when the budget runs out the findings made so far are kept. Tests: `gluedSuffixAndLongPrefixesAreFound` (`enc + "-"`, `enc + "_"`, `"item-" + enc`, `"token_" + enc`, `enc + "ab"`) and `prefixAndSuffixMatrixInBothAlphabets` (prefixes of 1 to 8 and suffixes of 0 to 3 characters, standard and URL-safe). |

Limit kept as documented: a glued alphanumeric prefix or suffix decodes to bytes next to the value, and a detector that
needs a word boundary can miss a value that has no separator of its own inside the encoded text (the matrix uses a
synthetic sentence, as a prompt would).
