(2) Any base64 run of 12 or more characters inside a second decoded layer is a third layer and `UNDECODABLE_BLOB`, whatever it decodes to; its views are still scanned so the event keeps the classes. | D-06 (P1) | **Fixed.** Reasons have a severity (`Base64Layers.worse`): a terminating reason (`UNDECODABLE_BLOB`, the limits) outranks `EMBEDDED_FILE`, in `Base64Layers.flag` within a field and in `BodyInspector.inspectJson` across fields. | D-07 (P1) | **Fixed.** A run that is not whole quanta of clean text is decoded at all four alignments (start offsets 0 to 3, each trimmed at the end to a multiple of 4), and every alignment goes through every view of D-05; the untrimmed whole run is read too, so an unpadded last quantum is not lost.
