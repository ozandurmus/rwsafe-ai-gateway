| D-01 (P0) | **Fixed.** `InspectionResult` can carry findings, and a rewrite, together with a non-verdict. `Base64Layers` keeps its findings when it sets a reason; `EMBEDDED_FILE` and `UNDECODABLE_BLOB` are soft (remembered, and the rest of the field and of the JSON body is still inspected and redacted), while `NORMALISATION`, `FINDING_LIMIT` and a spent decode budget stop the scan and still return the findings made so far. REQMOD takes the stronger of the non-verdict's flow action and the findings' action (`Action.max`, the non-verdict on a tie): a blocking finding blocks, a redaction applies where the flow allows the non-verdict. RESPMOD whole-body terminates when the non-verdict carries findings or is `UNDECODABLE_BLOB` (added to the terminating reasons). Events keep the class counts. Tests: `findingsSurviveAnEmbeddedFileOrABlob`, `findingsBesideABlobAreCountedOnTheFailClosedFlow`, `findingsBesideABlobStillDecideOnAFailOpenFlow`, `responseWithAFindingBesideAFileOrWithABlobIsTerminated`. |
| D-02 (P0) | **Fixed.** (1) Decoded bytes that are not strict UTF-8 are read as UTF-16LE when every other byte is mostly NUL, else as UTF-8 with NUL removed, else with replacement characters, and are scanned (and their runs decoded) before any blob decision; a recovered layer is still subject to the blob rule, so NUL padding cannot pass random bytes off as text. (2) A third layer that decodes to printable text is `UNDECODABLE_BLOB` at any length. (3) Entropy is the highest over any window of `min(length, 256)` characters, kept in one pass with a running sum of `c log c`. All linear, no regex. Tests: `nulInvalidAndUtf16LayersAreStillScanned`, `aReadableThirdLayerIsABlobAtAnyLength`, `paddingDoesNotDiluteEntropy`. |
| D-03 (P1) | **Fixed.** A run that does not decode to text as a whole is retried without its leading `- _ + /`, as each `/`-separated segment, and at offsets 1 to 3; a retry counts only when it decodes to printable text or a file signature, and its decoded bytes are charged to the per-field budget. At most six decodes per run character. A segment alone never exempts the whole run from the blob rule (a random standard-base64 blob contains `/`). Test: `prefixedAndPathGluedBase64IsRealigned`. |
| D-04 (P2) | **Fixed.** bzip2 needs `BZh`, a level `1`-`9` and the block or end-of-stream magic; `0x78 0x5e` counts as zlib only when the bytes are not strict UTF-8. Test: `textThatStartsLikeAMagicIsText`. |
